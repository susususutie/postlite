# UI 优化方案：右侧面板 Variable 布局

## 问题

右侧面板添加 Variable 后，表格宽度超出面板，出现横向截断

## 解决方案：双行卡片布局

### 修改文件

`src/components/EnvironmentManager.tsx`

### 实施步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 移除 `<Table>` 组件 | 删除 line 335-351 的 Table 配置 |
| 2 | 删除 `variableColumns` 变量 | 删除 line 203-289 的列配置 |
| 3 | 新增变量卡片渲染 | 用 `map` 遍历 `currentEnv.variables` |
| 4 | 创建双行布局 | 每行变量渲染为独立卡片 |
| 5 | 添加样式 | Flex 布局 + 悬浮效果 |

### 布局结构

```
┌────────────────────────────────────────┐
│  ┌─ Variable ─────────────────────┐    │
│  │ [Switch] [Input: name] [Select]  │  ← 第1行：启用+变量名+类型
│  │ [Input: value        ] [👁] [×]    │  ← 第2行：值+操作按钮
│  └─────────────────────────────────┘    │
│  ┌─ Variable ─────────────────────┐    │
│  │ ...                              │
│  └─────────────────────────────────┘    │
└────────────────────────────────────────┘
```

### 布局权重

| 元素 | 样式 | 作用 |
|------|------|------|
| 启用开关 | `width: 40px` | 固定宽度 |
| 变量名输入 | `flex: 1, minWidth: 80px` | 自适应 |
| 类型下拉 | `width: 90px` | 固定宽度 |
| 值输入框 | `flex: 1, minWidth: 60px` | 自适应 |
| 操作按钮 | `width: 64px` | 固定宽度，不遮挡 |

### 样式细节

- 卡片边框：`1px solid #d9d9d9`
- 卡片圆角：`borderRadius: 6px`
- 内边距：`padding: 12px`
- 间距：`margin-bottom: 12px`
- 悬浮效果：`box-shadow: 0 2px 8px rgba(0,0,0,0.1)`

### 预期效果

- ✅ 无横向滚动条
- ✅ 操作按钮固定右侧，不被遮挡
- ✅ 输入框自适应面板宽度
- ✅ 视觉层次清晰，卡片分隔明显
